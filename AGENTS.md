# hsync — Agent Guidance

`hsync-main` is the public meta-repository of HSYNC (README, contributing guide,
code of conduct, license, security policy and user documentation). It contains no
application source code.

* Code-level rules live in the monorepo root `AGENTS.md`, which is the single
  source of truth and drives the generated `.clinerules/` files via
  `scripts/dev/gen-clinerules.py`.
* Documentation in this repository follows the same Dual-Docs and English-only
  conventions described in the root `AGENTS.md`.
